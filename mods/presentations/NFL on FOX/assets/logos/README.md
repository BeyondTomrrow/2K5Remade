# FOX-supplied team-logo assets

The PNG files in this directory came from the user-supplied
`NFL-Fox-Logos-main.zip`. The FOX presentation package uses these files only;
it does not overwrite the shared `mods/teams/*/logos/scorebug.png` assets used
by other presentation packages.

File names are NFL 2K5 team abbreviations. This preserves the original ESPN,
CBS, and custom scorebug logo choices while the FOX package selects its own
asset set.
