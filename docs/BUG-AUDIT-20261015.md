Because the interpreted path executes SOFTDRINK's own changed code (not the
lifter's translation of it) and shows the same result, the defect follows
SOFTDRINK's code/data for Situation Mode, not native recompilation. "E2R" for
both teams means the Situation setup does not resolve team (and so stadium)
identity before the game loads. Next experiment: run SOFTDRINK's ISO in xemu
(the reference oracle, see memory notes) to see whether the original mod
behaves the same on Xbox; if it does not, diff the team-ID/stadium setup path
from Situation Settings between xemu and the port.

Status: **reproduced, isolated to SOFTDRINK, not fixed.**
