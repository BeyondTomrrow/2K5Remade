## What was built

* `src/nfl2k5_eras_capture.c` / `.h` (new):
  * `nfl2k5_eras_game_final(home, away)`: acts only when armed; skips when `[0xE602B8] == 0x0A`;
    reads score registers vs `[[0xE5FC28]]`/`[[0xE5FC68]]`, period, clock, old flow state, mode,
    play phase, timeouts, period points (block `+0x254 + 4q` and team `0x5B` scopes 1-5), team
    identity (city, nickname, code, ident, category, playbook), the team box (44 selectors via
    `sub_000CB2D0`, scope 0) and every live player's box (60 selectors via `sub_000CB240`,
    scope 0; players with `[[p+0x30]] == 0` skipped), plus each player's record pointer, name
    pointers `+0x10/+0x14`, names, jersey, position and photo (for the M2 check); cross-checks
    (registers vs scoreboard, period sum vs points, mode 4) go to `warnings`; then disarms.
  * A worker thread writes the box score JSON (`.tmp` then rename; never overwrites) and
    appends `game_id,home_pts,away_pts,final_period,end_state,final` to a results CSV.
  * `nfl2k5_eras_match_exit()`: still armed -> "abandoned" (log + status, no results row);
    captured -> "committed"; with the test switch it re-arms the next game.
  * API for M4: `nfl2k5_eras_capture_arm(game_id, box_path, results_csv)`, `_disarm()`,
    `_result(&Nfl2k5ErasResult)` (status IDLE / ARMED / FINAL / ABANDONED, score, period,
    end state, mode).
  * Test switch `NFL2K5_ERAS_CAPTURE=1`: arms at boot and after each match exit, writing
    `logs\eras-capture-<n>.json` and `logs\eras-capture-results.csv` through
    `xbox_user_path` (on this machine that is `%LOCALAPPDATA%\NFL2K5-PC\logs\`, because the
    dev root check compares `E:\NFL2K5-PC` with `E:/NFL2K5-PC`). `NFL2K5_ERAS_LOG=1` prints
    `[ERAS]` lines. Without the switch nothing is armed and both hooks return at once.
* `src/nfl2k5_eras_selectors.h` (new, generated) by `build/eras/result-capture/capture_table.py`
  from `data/eras/stat_selectors_2k5.json` (checks every selector exists and has a getter for
  its entity; `--check` verifies the header is current). Keys of unsettled selectors are
  neutral (`sel_62`, `sel_63`, `sel_30`).
* `src/recomp_manual.c`: `nfl2k5_guest_player_stat` generalised into exported
  `nfl2k5_guest_stat(fn_va, fn, entity, selector, scope, *out)` (saves/restores all guest
  registers, lazy flags, x87 and XMM; real return sites 0x3216D9 / 0x1353AB), plus
  `nfl2k5_guest_player_stat_scope` and `nfl2k5_guest_team_stat`; the live-QB wrapper keeps
  its old +-10000 range check and `[LIVE-QB-ABI]` message. New `nfl2k5_eras_interp_hooks()`
  registers `0x000A2910` (reads `g_ecx/g_edx`) and `0x000645D0` (14 of 32 hook slots used).
* `src/main.c`: calls `nfl2k5_eras_interp_hooks()` and `nfl2k5_eras_capture_init()` after
  `nfl2k5_scorebug_interp_hooks()`.
* `config/game.cmake`: `src/nfl2k5_eras_capture.c` added.
* `tools/apply-gen-patches.py`: `ERAS_GAME_FINAL` (sub_000A2910, after `loc_000A2910: ;`,
  applied in `recomp_0004.c`) and `ERAS_MATCH_EXIT` (sub_000645D0, after `loc_000645D0: ;`,
  applied in `recomp_0002.c`), exactly as the plan gives them.
* Test infrastructure (not in the plan, needed to test safely while the PC is in use):
  * `src/nfl2k5_input_hle.c`: `NFL2K5_NO_HOST_PAD=always` never reads (or rumbles) host
    controllers. With `=1` the host pad is live again 15 s after the last scripted press;
    in the first attempt a real pad's inputs (A, d-pad, L3/R3) reached the hidden test game.
    Default behaviour is unchanged.
  * `tools/eras-capture-test.ps1` (new): launch / press / shot / play / stop for these tests,
    background env vars, `--retail`, `NFL2K5_NO_HOST_PAD=always`, `NFL2K5_RENDER_SCALE=1`
    (the saved scale 9 ran at about 2 fps beside other GPU work, so a 4-minute game would
    have taken hours), A tapped every 10 s during play until the log matches.
  * `tools/bg-drive.ps1` (untracked, existing): `NFL2K5_NO_HOST_PAD` set to `always`.

Optional item not done: `is_final()` in `src/nfl2k5_presentation.cpp` still guesses; it can

## Known defects and notes for later milestones

* Match exit sees period and flow state already reset to 0; only the final whistle has the
  score. An abandoned game's score is not available at exit.
* A Rematch replays without passing match exit: in an Eras game the second game is simply not
  captured (first result stands). Hiding Rematch remains a later item (plan risk 9).
* The attract-mode demo is a mode-4 match that passes match exit; harmless unless something
  arms the capture while sitting on the title screen.
* Background tests need `NFL2K5_RENDER_SCALE=1` and `NFL2K5_NO_HOST_PAD=always` on this PC.
* `xbox_user_path` resolves to `%LOCALAPPDATA%\NFL2K5-PC` here, not the checkout: M3's
  `eras\league1\` will live there too.
