# Included extraction runtime

QuickBMS 0.12.0 and the Madden TERF script are by Luigi Auriemma.
The executable is unmodified. It is used only to read game archives and write
decompressed copies into a separate destination.

Official project and source downloads: https://aluigi.altervista.org/quickbms.htm
Source archive: https://aluigi.altervista.org/papers/quickbms_src.zip
Script: https://mirror.aluigi.org/bms/madden_terf.bms

QuickBMS is GPL 2.0; see quickbms.txt for the author's notices, usage, credits,
and the statement permitting distribution of the original executable.

The Windows application also includes Python, Tcl/Tk, and NumPy through
PyInstaller. Their original distribution notices accompany the runtime.
Game models and textures are separate user-owned local assets; the application
source distribution itself does not contain game archives.
