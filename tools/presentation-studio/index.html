Import HTML as a presentation package

Choose a folder holding an HTML page with its CSS, JavaScript and images, or choose the files directly. They are copied into a new folder under mods/presentations; the originals are not changed.

The entry page gets two additions so it works in the game and here: the Presentation API runtime (game data and events, NFL2K5.onState / NFL2K5.onEvent) and layout.css for visual edits. Its canvas is 1920×1080.
